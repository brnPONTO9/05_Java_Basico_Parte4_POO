# Java Básico – Parte 4: Programação Orientada a Objetos

Exercícios 1 a 50, cada um em sua pasta (`ex01` a `ex50`) com o pacote correspondente. O exercício 18 usa os pacotes `br.edu.modelo` e `br.edu.app`.
Temas: classes, encapsulamento, herança, polimorfismo, abstração, interfaces, enums, records, sealed, SOLID e injeção de dependência.

## Como executar
    javac -encoding UTF-8 -d out $(find . -name "*.java")
    java -cp out ex01.Exercicio01
